2. VERSIONES
[ ] Confirmamos con la persona responsable que el contenido está vigente.
[ ] Las páginas están completas y son legibles.
[ ] El logo, los campos y el orden del documento son correctos.
[ ] Apartamos las versiones antiguas para evitar confusiones.

3. CAPTURA
[ ] Marcamos los datos que aparecen en más de un documento.
[ ] Acordamos un significado común para cada campo compartido.
[ ] Distinguimos datos reutilizables de los que se confirman en cada visita.
[ ] Definimos qué hacer si falta un dato o hay una corrección.

4. RESPONSABLES Y RESGUARDO
[ ] Asignamos quién revisa el paquete antes de firmar, imprimir o archivar.
[ ] Definimos quién puede acceder a los documentos.
[ ] Acordamos dónde guardar el paquete y cómo reconocer la versión final.
[ ] Si usamos WhatsApp, definimos el canal y los datos que manejará.

5. PRUEBA CON DATOS FICTICIOS
[ ] Capturamos una vez y revisamos todos los documentos elegidos.
[ ] Probamos nombres largos, acentos y campos vacíos.
[ ] Corregimos un dato y verificamos todos los formatos afectados.
[ ] Revisamos la impresión, el orden de las páginas y las firmas pendientes.
[ ] Otra persona de recepción pudo repetir el flujo.
[ ] Localizamos el paquete final después de terminar la prueba.
